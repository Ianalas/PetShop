# 🐾 PetShop

## Sobre 

O **PetShop** é uma aplicação desenvolvida para facilitar o gerenciamento de serviços e produtos para animais de estimação. O sistema permite que clientes encontrem serviços para seus pets, como banho e tosa, e explorem produtos disponíveis para compra.

Este projeto também serviu como aprendizado para o uso de **Webpack** e **bundlers**, garantindo compatibilidade da página com diversos navegadores e melhorando a otimização do código.

## 🚀 Tecnologias Utilizadas

Este projeto foi desenvolvido utilizando as seguintes tecnologias:

- **HTML5** - Estrutura do site
- **CSS3** - Estilização da interface
- **JavaScript (ES6+)** - Lógica interativa e dinâmica
- **Webpack** - Empacotamento e otimização dos arquivos
- **Bundlers** - Para compatibilidade com múltiplos navegadores

## 📷 Layout

O design da aplicação foi pensado para proporcionar uma experiência amigável e intuitiva, garantindo fácil navegação e usabilidade em diferentes dispositivos.

## 🛠️ Como Executar

Para visualizar o projeto, siga os passos abaixo:

### 1️⃣ Clone o repositório
```bash
git clone https://github.com/Ianalas/PetShop.git
```

### 2️⃣ Acesse a pasta do projeto
```bash
cd PetShop
```

### 3️⃣ Instale as dependências
```bash
npm install
```

### 4️⃣ Execute o Webpack para empacotamento
```bash
npm run build
```

### 5️⃣ Abra o arquivo `dist/index.html`
Após a build, abra o arquivo gerado dentro da pasta `dist/` em um navegador de sua escolha.

## 📄 Funcionalidades

- Página inicial apresentando os serviços do pet shop
- Exibição de produtos disponíveis para compra
- Contato para agendamentos e informações
- Design responsivo para melhor experiência em qualquer dispositivo
- Uso de Webpack e bundlers para otimização e compatibilidade
